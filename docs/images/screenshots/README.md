# Windows 截图采集规范

真实界面截图由 Windows 安装包验收环境采集，再提交到此目录。截图用于 README 和首次使用指南，不使用生成图或浏览器模式截图代替 Windows 桌面版界面。

## 建议文件

- `windows-main.png`：行情已加载的主界面，包含价格、更新时间和数据状态。
- `windows-alerts.png`：已展开的预警阈值与目标价观察区域。
- `windows-settings.png`：设置窗口中的通用设置或摘要通知页。

## 采集要求

- 使用当前正式 Release，窗口保持常规尺寸，截图清晰且不裁切关键区域。
- 不展示真实邮箱、Webhook 地址、API Key、授权码、个人持仓金额、用户名、本地路径或完整诊断报告。
- 行情价格、时间和数据源可以保留；如需遮挡，使用不影响布局的统一灰色遮挡块。
- 每张截图只展示一个明确的使用场景，不混入无关窗口和系统通知。
- 提交前确认图片与当前版本界面一致；界面变更后及时更新对应截图。
