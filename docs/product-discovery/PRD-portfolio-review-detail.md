# 持仓详情复盘增强 PRD

## 1. Summary

本文档定义 GoldMonitor 桌面端右侧面板的“持仓详情复盘增强”。目标是在单个持仓详情中集中展示盈亏、流水、预警、风险分析和行情质量线索，让用户不用在多个区域来回切换也能完成一次持仓复盘。

本版本只增强桌面端持仓详情视图。不新增账户体系、移动端页面、云同步、多品种资产或自动交易建议。

## 3. Background

GoldMonitor 已经具备黄金实时价格、持仓、流水、预警、告警记录、风险分析和行情质量能力。当前问题不是缺少数据，而是单个持仓详情里缺少一个清晰的复盘入口。

用户查看某个持仓时，通常需要回答这些问题：

- 这个持仓当前赚亏多少。
- 最近买卖了什么。
- 是否触发过预警。
- 风险分析和行情质量是否影响判断。
- 下一步是加仓、减仓、设置提醒，还是导出记录。

现有右侧面板中这些信息分散在持仓列表、流水页、警报记录和风险分析入口里。用户需要多次切换，复盘链路不够直接。

## 4. Objective

目标是在持仓详情中建立一个桌面端复盘工作台。用户打开某个持仓详情后，可以先看到关键盈亏和状态，再通过“概览 / 流水 / 预警 / 复盘”标签进入对应内容。

### 为什么重要

- 降低复盘时的信息查找成本。
- 让持仓、流水、预警、风险分析和行情质量形成闭环。
- 为后续更完整的复盘报告、数据质量判断和风险操作路径打基础。

### Key Results

- KR1：用户打开任一持仓详情后，可以在第一屏看到持仓名称、状态、合计盈亏、当前价、平均成本和数量。
- KR2：持仓详情内提供“概览 / 流水 / 预警 / 复盘”四个标签，默认进入“复盘”。
- KR3：“复盘”标签中至少展示近 7 日流水、触发预警、风险分析、数据质量四类摘要。
- KR4：“复盘线索”中能展示关联流水、持仓提醒、告警记录、风险分析和行情质量中的可用信息。
- KR5：详情内操作收敛为一个“操作”下拉菜单，点击其他右侧面板下拉或空白区域时可以自动收起。

## 5. Market Segment(s)

本功能面向使用 GoldMonitor 做个人黄金持仓监控的桌面端用户。

用户任务不是高频交易，而是低频、审慎地记录持仓、观察价格、处理预警并复盘决策依据。因此界面应保持信息密度高、层级清晰、操作路径短。

约束：

- 用户当前主要在桌面网页使用。
- 数据来自本地持仓、流水、预警、告警记录、风险分析历史和行情质量状态。
- 不把界面文案写成投资建议。
- 不要求每条风险分析都能精确关联到某个持仓，本版本作为市场上下文展示。

## 6. Value Proposition(s)

### 用户要完成的工作

- 快速判断某个持仓当前状态。
- 查看该持仓相关买卖流水。
- 确认是否有预警条件或触发记录。
- 把风险分析和行情质量作为复盘参考。
- 导出当前持仓复盘内容，方便留存。

### 用户获得的收益

- 少切换页面。
- 少记忆上下文。
- 更容易看出一次持仓变化和预警、风险之间的关系。
- 操作更集中，详情内能完成新增流水、设置提醒和导出复盘。

### 避免的痛点

- 不再只看到孤立的盈亏数字。
- 不需要从警报记录中人工查找相关线索。
- 不需要在持仓详情中塞满多个并列按钮。
- 不因文字换行和空白过大降低信息密度。

## 7. Solution

### 7.1 UX / Prototype

持仓详情采用以下桌面端结构：

```text
持仓详情
┌──────────────────────────────────────┐
│ 名称 + 状态                    操作  │
│ 单位 · 数量 · 当前价 · 最近交易       │
│ 合计盈亏                              │
├──────────────────────────────────────┤
│ 概览  流水  预警  复盘               │
├──────────────────────────────────────┤
│ 近7日流水 | 触发预警 | 风险分析 | 数据质量 │
├──────────────────────────────────────┤
│ 复盘线索                              │
│ 时间   类型   标题/摘要               │
├──────────────────────────────────────┤
│ 关联流水                              │
│ 日期   类型   成交价   数量   结果     │
├──────────────────────────────────────┤
│ 新增流水      设置提醒      导出复盘   │
└──────────────────────────────────────┘
```

标签说明：

- 概览：展示持仓关键指标和最近流水摘要。
- 流水：展示当前持仓的关联流水。
- 预警：展示提醒状态和提醒编辑入口。
- 复盘：展示摘要、复盘线索、关联流水和底部操作。

### 7.2 Key Features

#### 持仓详情头部

- 展示持仓名称。
- 展示当前持仓状态，如盈利、亏损、接近成本、触发预警、等待行情。
- 展示合计盈亏。
- 展示单位、数量、当前价和最近交易日期。
- 右侧只保留一个“操作”按钮，点击后出现下拉菜单。

操作下拉菜单包含：

- 新增买入。
- 新增卖出。
- 编辑持仓。
- 设置提醒。
- 查看全部流水。

#### 详情标签

详情内有四个标签：

- 概览。
- 流水。
- 预警。
- 复盘。

默认打开“复盘”。切换标签只影响当前详情内容，不改变全局持仓 / 流水 / 复盘页。

#### 复盘摘要

复盘摘要展示四项：

- 近 7 日：当前持仓近 7 日流水数量。
- 触发预警：当前持仓提醒是否触发，以及匹配到的告警数量。
- 风险分析：当前风险分析历史数量和最近风险等级。
- 数据质量：当前行情质量分数和标签。

当某类数据不存在时，展示清晰的空状态，不展示错误或占位乱码。

#### 复盘线索

复盘线索按时间倒序展示，来源包括：

- 当前持仓关联流水。
- 当前持仓提醒状态和最近触发信息。
- 与持仓名称或持仓 ID 匹配的告警记录。
- 最近风险分析历史。
- 当前行情质量状态。

第一版允许风险分析和行情质量作为市场上下文展示，不强制绑定到某个持仓。

#### 关联流水

在复盘标签中展示紧凑流水表：

- 日期。
- 类型。
- 成交价。
- 数量。
- 已实现或成交额。

无流水时展示“暂无关联流水”。

#### 底部操作

复盘标签底部提供三个操作：

- 新增流水：默认进入当前持仓买入流水。
- 设置提醒：进入预警标签并展开提醒编辑器。
- 导出复盘：导出当前持仓复盘 Markdown 文件。

### 7.3 Technology

本版本使用现有前端静态资源实现：

- `static/app.js` 负责详情标签状态、复盘线索组装、导出 Markdown 和菜单交互。
- `static/app.css` 负责桌面端紧凑布局和下拉样式。
- `tests/frontend_asset_check.py` 负责锁定前端函数、类名和交互契约。

不新增后端接口。不修改持仓、流水、预警的数据存储格式。

### 7.4 Data Contract

本版本读取以下现有数据：

- `portfolioState.items`：持仓列表。
- `portfolioState.transactions`：流水列表。
- `portfolioState.alerts.items`：持仓提醒。
- `alertEntries`：告警记录。
- `riskAnalysisHistory`：风险分析历史。
- `latestSourceHealthState.quality`：行情质量。
- `latestData`：当前行情数据。

前端组合规则：

- 流水通过 `position_id` 精确关联。
- 持仓提醒通过 `position_id` 精确关联。
- 告警记录优先匹配 `position_id`，没有该字段时用持仓名称或 ID 在消息、标题、备注中匹配。
- 风险分析和行情质量作为市场上下文，不做精确持仓归因。

### 7.5 Exception Paths

- 没有关联流水：复盘线索仍展示提醒、风险分析或行情质量；关联流水区域展示空状态。
- 没有提醒：预警标签展示未设置状态，并提供编辑提醒入口。
- 没有风险分析历史：复盘摘要展示暂无分析。
- 没有行情质量：复盘摘要展示等待检查。
- 下拉菜单打开后点击外部区域：菜单自动收起。
- 切换到其他右侧面板下拉：当前详情菜单自动收起。

### 7.6 Not In Scope

- 移动端专项布局。
- 云同步。
- 账户体系。
- 多品种贵金属。
- 自动交易建议。
- 后端新增复盘接口。
- 复杂图表和长报告编辑器。

## 8. Release

### First Version

首版完成桌面端持仓详情复盘增强：

- 详情头部重组。
- 操作下拉。
- 详情内四个标签。
- 复盘摘要。
- 复盘线索。
- 关联流水紧凑表。
- 当前持仓复盘导出。

### Future Versions

后续可以在当前基础上扩展：

- 更精确的告警到持仓关联字段。
- 后端生成标准化复盘报告。
- 复盘线索筛选。
- 持仓风险评分。
- 多持仓对比复盘。

### Acceptance Criteria

- 打开持仓详情后默认进入“复盘”标签。
- 详情头部只有一个“操作”下拉入口承载多项操作。
- 概览、流水、预警、复盘四个标签可以切换。
- 复盘标签展示四项摘要。
- 复盘线索至少能展示关联流水和行情质量线索。
- 有流水时展示关联流水表；无流水时展示空状态。
- 点击“设置提醒”后进入预警标签并展开提醒编辑器。
- 点击“导出复盘”可以下载当前持仓复盘 Markdown。
- 点击详情下拉外部区域后下拉自动收起。
- 现有前端资源检查、JavaScript 语法检查和相关 Python 测试通过。
