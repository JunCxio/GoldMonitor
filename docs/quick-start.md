# GoldMonitor 首次使用指南

本指南面向第一次使用 GoldMonitor 的普通用户。完成下面四步后，你可以确认行情可用、设置一条本地预警，并按需要启用通知或风险分析。

![GoldMonitor 功能一览](images/feature-overview.svg)

## 1. 安装并打开程序

1. 打开 [最新发布页面](https://github.com/JunCxio/GoldMonitor/releases/latest)。
2. Windows 下载并运行 `GoldMonitorSetup.exe`。安装在当前用户目录，通常不需要管理员权限。
3. macOS 下载 `GoldMonitor-macOS.dmg`，把 `GoldMonitor.app` 拖入“应用程序”目录。
4. 首次打开时等待主界面右上角状态从“连接中...”变为可用状态。

如果状态持续异常，先点击价格卡片中的“重新获取”。仍无法恢复时，在“数据状态”区域查看数据源详情，并按 [数据源异常模板](https://github.com/JunCxio/GoldMonitor/issues/new/choose) 提交脱敏反馈。

## 2. 确认行情与单位

主界面默认展示人民币克价。你可以在顶部切换：

- “国内金价”：人民币/克。
- “国际金价”：USD/oz。

确认价格卡片中显示价格、更新时间和数据状态后，再开始设置预警。行情出现缓存回退或长时间未更新时，不建议据此做交易决策。

## 3. 设置第一条预警

1. 在右侧“预警中心”点击“新增规则”。
2. 选择价格、波动、目标价或持仓规则，填写名称、单位和触发条件。
3. 按需要设置生效时间、失效时间和独立冷却时间。未设置时继承全局提醒冷却时间。
4. 选择通知策略：继承全局、指定本机/邮件/Webhook，或“仅记录”。
5. 保存后确认规则出现在列表中，并检查状态是否为“监控中”或“等待数据”。
6. 打开设置，在“通用设置”中使用“触发测试”检查本机弹窗和提示音。

预警只会在规则有效且满足条件时触发。为了减少重复打扰，可在规则中单独设置冷却时间，也可在“通用设置”中设置全局冷却时间和静默时段。需要复用某条规则时可直接复制；需要复用一组价格和波动设置时，使用“预警策略模板”的“保存当前”。

规则较多时，可使用名称搜索和状态筛选缩小范围，再选择当前结果进行批量启用、停用、重置或删除。批量删除不会删除已经保存的历史警报记录。

点击规则的“详情”可查看当前值、目标值、距触发差距和等待数据等具体原因。详情还会汇总最近 30 天的触发次数、通知送达率、处理率和 24 小时后行情延续率；该延续率只用于复盘，不代表预测准确率或投资建议。

新建或编辑价格、波动、目标价和持仓规则时，可在保存前选择 7 天、30 天或 90 天运行历史模拟。价格类规则使用本地历史行情计算规则命中、冷却后触发、被抑制次数和时段分布；持仓规则会结合本地流水与历史行情还原数量、成本和浮动盈亏。模拟不会修改规则、持仓或历史数据；历史覆盖不足、波动窗口小于采样间隔或持仓流水缺少交易日期时，页面会明确说明无法可靠模拟。

预警记录中的“查看规则”会返回对应规则；如果原规则已经删除，可使用“复制规则”根据触发时快照创建草稿。

## 4. 按需启用通知和风险分析

### 邮件或 Webhook 通知

1. 打开右上角“设置”。
2. 在“邮件通知”或“Webhook”页填写渠道信息。
3. 分别点击“发送测试”，确认接收端可用后再依赖正式预警。

SMTP 授权码、Webhook 地址和 API Key 不应出现在截图、Issue 或诊断报告中。程序会优先把这些敏感信息保存到系统凭据存储。

### 每日摘要

在“摘要通知”页启用每日摘要，选择发送时间和已配置的邮件或 Webhook 渠道。先使用“生成预览”检查内容；“测试发送”不会占用当天的计划发送资格。摘要会同时列出定投计划数量、下一次计划、最近执行结果和需要处理的异常计划。

### 持仓定投

1. 在主界面的“持仓”区域切换到“定投”。
2. 新建计划，填写计划名称，并选择已有持仓或输入首次执行时要创建的持仓名称。
3. 选择人民币或美元，填写每期固定金额、手续费、每天/每周/每月/每年周期和执行时间；每周计划需选择星期一至星期日。需要阶段性执行时，可设置开始日期、结束日期或目标期数；日期留空表示长期有效，目标期数留空表示不限制执行次数。
4. 表单会按当前周期和执行区间展示未来 5 期；设置目标期数后还会展示预计总投入、剩余投入和预计完成日期。修改金额、手续费、周期、日期、时间或执行区间后会自动重新计算，也可手动使用“重新计算”。保存后可暂停、重新启用、编辑、复制、归档或使用“立即执行”检查生成的买入流水。临时不想执行当前一期时，可使用“跳过本期”，计划会保持启用并自动推进到下一期，不生成买入流水。复制会生成默认暂停的新计划草稿，修改名称、持仓或周期并确认后再保存，不会立即执行。

计划完成首次执行后，点击“编辑”展开计划，可查看累计投入、手续费、执行次数、累计数量、定投均价、当前市值、盈亏及最近 10 条执行记录。点击“导出全部记录”可将该计划仍保存在本地的全部执行流水保存为 CSV。指标与导出都只统计该计划生成的定投流水；手动新增的普通流水不会计入。当前行情不可用时，历史投入和均价仍可查看，市值与盈亏会显示等待行情估值。归档计划会立即停止运行，但仍可在“已归档”中查看绩效和导出记录；恢复后默认保持暂停，需要手动启用。永久删除只在归档后开放，删除计划不会删除已生成的持仓流水。

定投概览会分别汇总近 30 天实际投入和未来 30 天计划投入，人民币与美元独立显示，不进行汇率换算。实际投入按已经生成的定投买入流水统计，即使计划随后暂停、归档或删除，历史投入仍会保留；未来投入只包含启用且仍可执行的计划，遵守开始日期、结束日期和剩余目标期数，并按计划列出预计投入、单期金额及首末执行日期。计划较多时可在明细区域内滚动查看。计划卡片会展示下一次执行和随后 3 个日期，便于检查月末、闰年和执行区间边界。设置目标期数后，卡片和绩效区域会展示已完成期数与剩余期数；只有实际生成的定投买入流水计入进度，跳过本期不占用目标期数，达到目标后计划自动完成并停止继续生成流水。计划执行时使用对应单位的最新有效行情计算数量。开始日期前计划显示“待开始”且不会手动或自动执行；结束日期后会补完范围内最后一期并显示“已完成”，不会继续生成流水。跳过操作只跳过页面显示的当前期次；若执行时间已经变化，系统会要求刷新后重试，避免连续误跳。没有有效行情时计划会保留并显示“等待行情”；关联持仓被删除时计划会自动暂停并提示重新选择。应用关闭期间不会逐期补齐所有历史计划，只会在再次启动后补最近一期；重新启用计划不会补停用期间的历史期次。

定投只生成本机持仓流水，不会连接券商、银行、交易所或其他交易平台，也不会执行真实下单。生成的流水会标记“定投”，计划异常、到期状态和当日执行结果可在“今日概览”查看。

### 风险分析

风险分析默认关闭，且仅在你手动点击“风险分析”后调用模型服务：

1. 在设置的“风险分析”页启用助手。
2. 选择 DeepSeek 或 OpenAI 兼容服务，并完成模型与 API Key 配置。
3. 返回主界面，确认当前行情正常后点击“风险分析”。

风险分析用于辅助判断，不构成投资建议。没有行情、数据状态异常或模型配置不完整时，程序会提示具体原因。

## 数据与隐私

GoldMonitor 的配置和运行数据默认保存在本机：

- Windows：`%APPDATA%\GoldMonitor`
- macOS：`~/Library/Application Support/GoldMonitor`

在提交 Issue 前，请删除 API Key、SMTP 授权码、Webhook 地址、用户数据、完整诊断报告和可识别个人身份的本地路径。安全问题请使用 [私密报告入口](https://github.com/JunCxio/GoldMonitor/security/advisories/new)。

## 需要帮助

- 程序缺陷：使用“Bug 报告”模板。
