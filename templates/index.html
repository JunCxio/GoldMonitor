设置

管理桌面行为、通知渠道、风险分析和本机数据。

通用设置

控制应用在桌面上的运行方式

这些设置只影响当前设备，不会修改行情、持仓或预警数据。

启动与窗口

配置开机启动和主窗口关闭行为。

开机自启动
开机后自动启动金价监控。
自启动时进入托盘
开机启动后不弹出主窗口，可从右下角托盘打开。
关闭窗口时
控制点击右上角关闭按钮后的行为。

桌面价格显示

选择悬浮条、任务栏价格或两处同时显示。

桌面金价悬浮条
主窗口隐藏时，仍在桌面右下角显示当前金价。
Windows 显示位置
任务栏模式仅使用可确认的空白区域；任务栏自动隐藏、全屏或空间不足时会暂时隐藏。
任务栏选择
可跟随系统主任务栏，也可固定到具体显示器。固定目标暂时不可用时不会切换到其他屏幕。
悬浮条显示内容
控制桌面悬浮条显示人民币、美元或组合内容。
悬浮条尺寸
极简适合长期贴边显示，标准模式保留更多状态信息。
悬浮条透明度
范围 50 到 100，数值越高越不透明。
悬浮条贴边吸附
拖动到屏幕边缘附近时自动贴齐。
悬浮条始终置顶
保持在普通窗口上方；配合全屏自动隐藏可避免覆盖视频和演示。
其他应用全屏时自动隐藏
检测到其他应用进入全屏后隐藏，退出全屏时自动恢复。
锁定悬浮条位置
防止误拖动，双击打开主界面和右键菜单仍可使用。

提醒行为

控制本机提醒方式、冷却时间和静默时段。

告警提示音
达到预警条件时播放系统提示音。
系统级告警弹窗
达到预警条件时弹出置顶提示框。
测试提醒
触发一条手动测试提醒，用于检查弹窗、声音和通知链路。
提醒冷却时间
同一类型提醒在冷却期内只记录，不重复弹窗或发送通知。
静默时段
该时间段内只记录提醒，不弹窗、不响铃、不发送通知。
至
自动重试失败通知
仅重试发送失败的邮件或 Webhook，不重复已成功渠道；失败后每 10 分钟重试，最多 3 轮并限于 24 小时内。
正在读取重试队列。
邮件通知

配置邮件服务与通知内容

授权码仅保存在本机凭据存储中，导出普通配置时不会包含原文。

SMTP 连接

填写服务地址、端口和加密方式。

SMTP 服务器
邮件服务商 SMTP 地址，例如 smtp.qq.com。
端口
SSL 通常为 465，TLS 通常为 587。
加密方式
使用 SSL 或 TLS 建立加密连接。

账户与密钥

配置发件账户、授权码和收件地址。

发件邮箱
用于发送通知的邮箱地址。
SMTP 授权码
未保存授权码。输入授权码后保存即可启用邮件发送。
收件邮箱
接收金价预警通知的邮箱。
连接测试
发送一封测试邮件验证当前配置。

通知模板

自定义预警邮件的标题和正文。

邮件标题模板
支持 {level}、{title}、{price_rmb}、{price_usd}、{rate}。
邮件正文模板
支持 {message}、{time}、{gold_source}、{rate_source} 等占位符。
Webhook

将预警发送到外部服务

使用 HTTPS 地址接收结构化 JSON，可连接企业协作工具或自建服务。

连接与投递

配置接收地址和需要投递的预警级别。

启用 Webhook
达到预警条件时向 Webhook 地址发送 JSON 通知。
Webhook 地址
支持企业微信、钉钉和自建 HTTPS 接收地址。
通知级别
分别控制价格、关键和波动预警是否发送。
连接测试
发送一条测试请求验证地址是否可用。
摘要通知

定时汇总最近 24 小时的重要信息

摘要包含行情、预警、风险分析、新闻、数据质量、持仓和定投计划。

发送计划

设置每日运行时间和发送渠道。

启用每日摘要
按本地时间执行每日摘要任务。
发送时间
程序在设定时间后启动时，会补发当天尚未完成的摘要。
发送渠道
邮件与 Webhook 可独立启用，并复用各自连接配置。
任务状态
显示当前计划、渠道和最近一次执行结果。
状态尚未加载。

预览与测试

先检查摘要内容，再决定是否测试发送。

摘要操作
预览和测试都不会占用当天计划任务的完成状态。
预览内容
测试发送使用相同内容及已保存的渠道配置。
风险分析

配置分析模型和单次调用成本

模型只在手动执行风险分析或连接测试时调用，不会后台自动消耗 token。

分析策略

控制功能状态、分析深度和模型提供商。

启用风险分析助手
关闭后将隐藏手动风险分析入口。
分析深度
快速模式消耗更少，深度模式会使用更多历史样本。
模型提供商
可使用 DeepSeek 或 OpenAI 兼容服务。

模型连接

配置当前提供商的接口地址、模型和密钥。

DeepSeek API 地址
默认使用 DeepSeek 官方 OpenAI 兼容接口。
DeepSeek 模型
默认模型为 deepseek-v4-pro，可从接口自动获取。
DeepSeek API Key
未保存密钥。输入 API Key 后保存即可启用该模型。
兼容接口地址
填写兼容服务的基础地址，例如 https://example.com/v1。
兼容模型
填写兼容服务支持的模型名称。
兼容 API Key
未保存密钥。输入 API Key 后保存即可启用该接口。
模型连接测试
发送一次轻量生成请求，不保存风险分析结果。

成本控制

限制输出规模并避免短时间重复调用。

单次输出上限
限制每次分析的最大输出 token。
分析冷却时间
两次手动分析之间的最短间隔。
重复分析缓存
同一行情快照在此时间内复用最近分析。

完整数据归档

恢复完整数据

数据健康状态

重建汇总数据

修复预览
