设置

开机自启动
开机后自动启动金价监控。
自启动时进入托盘
开机启动后不弹出主窗口，可从右下角托盘打开。
桌面金价悬浮条
主窗口隐藏时，仍在桌面右下角显示当前金价。
悬浮条显示内容
控制桌面悬浮条显示人民币、美元或组合内容。
悬浮条尺寸
极简适合长期贴边显示，标准模式保留更多状态信息。
悬浮条透明度
范围 50 到 100，数值越高越不透明。
悬浮条贴边吸附
拖动到屏幕边缘附近时自动贴齐。
关闭窗口时
控制点击右上角关闭按钮后的行为。
告警提示音
达到预警条件时播放系统提示音。
系统级告警弹窗
达到预警条件时弹出置顶提示框。
测试提醒
触发一条手动测试提醒，用于检查弹窗、声音和通知链路。
提醒冷却时间
同一类型提醒在冷却期内只记录，不重复弹窗或发送通知。
静默时段
该时间段内只记录提醒，不弹窗、不响铃、不发送通知。
SMTP 服务器
邮件服务商 SMTP 地址 (如 smtp.qq.com)。
端口
SSL 通常为 465，TLS 通常为 587。
加密方式
SSL 或 TLS 加密连接。
发件邮箱
用于发送通知的邮箱地址。
SMTP 授权码
未保存授权码。输入授权码后保存即可启用邮件发送。
已保存授权码
不再使用当前授权码时，可删除本机保存的授权码。
收件邮箱
接收金价预警通知的邮箱。
测试邮件
发送一封测试邮件验证配置是否正确。
邮件标题模板
支持 {level}、{title}、{price_rmb}、{price_usd}、{rate}。
邮件正文模板
支持 {message}、{time}、{gold_source}、{rate_source} 等占位符。
启用 Webhook
达到预警条件时向 HTTPS Webhook 地址发送 JSON 通知。
Webhook 地址
支持企业微信、钉钉、自建服务等 HTTPS 接收地址。
Webhook 分级
分别控制价格预警、关键预警和波动预警是否发送 Webhook。
测试 Webhook
发送一条测试 JSON 请求验证地址是否可用。
启用风险分析助手
仅在手动点击风险分析时调用模型，不会自动消耗 token。
分析深度
快速模式消耗更少，深度模式会使用更多历史样本。
模型提供商
当前版本优先支持 DeepSeek。
DeepSeek API 地址
默认使用 DeepSeek 官方 OpenAI 兼容接口。
DeepSeek 模型
默认模型为 deepseek-v4-pro，可从接口自动获取。
DeepSeek API Key
未保存密钥。输入 API Key 后保存即可启用该模型。
已保存 DeepSeek Key
不再使用当前密钥时，可删除本机保存的 DeepSeek API Key。
兼容接口地址
填写 OpenAI 兼容服务的基础地址，例如 https://example.com/v1。
兼容模型
填写兼容服务支持的模型名称。
兼容 API Key
未保存密钥。输入 API Key 后保存即可启用该接口。
已保存兼容 Key
不再使用当前密钥时，可删除本机保存的兼容 API Key。
模型连接测试
仅调用模型列表接口验证当前配置，不触发风险分析。
单次输出上限
限制每次分析的最大输出 token，控制成本。
分析冷却时间
两次手动分析之间的最短间隔，避免误点重复消耗。
重复分析缓存
同一行情快照在此时间内复用最近分析，避免重复消耗 token。
导出配置
导出本机设置、阈值和通知配置，备份文件不包含密钥原文。
导入配置
粘贴配置备份 JSON 后导入，会覆盖当前相关配置。
诊断报告
导出版本、数据源状态、最近日志和配置摘要，便于排查问题。
导出目录
配置备份和诊断报告会保存到固定目录，便于查找。
恢复默认设置
重置通用、邮件、风险分析和提醒设置，并清空阈值。

风险分析助手

点击开始分析，助手会基于当前时间、金价、汇率、历史走势和近期资讯生成风险趋势判断。
